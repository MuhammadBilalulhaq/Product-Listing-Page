# 🛍️ Shopping Website

A simple shopping website built using **HTML, CSS, Bootstrap, and JavaScript**. The project displays products in cards and allows users to filter products by brand, category, color, size, and price.

## ✨ Features

- **Product Display:** Shows products with images, names, brands, descriptions, sizes, colors, and prices.
- **Brand Filter:** Filter products by brand.
- **Category Filter:** Browse products by category.
- **Color Filter:** Find products by color.
- **Size Filter:** Filter products by size.
- **Price Filter:** Find products within a selected price range.
- **Reset Filters:** Clear all selected filters and display all products again.
- **Responsive Design:** Uses Bootstrap to make the website suitable for different screen sizes.
- **Product Cards:** Displays products in a clean card layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure the product images are inside the `Assets` folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Select different filters to explore the products.
6. Click **Reset Filters** to display all products again.

## 🎯 Project Objective

The objective of this project is to practice HTML, CSS, Bootstrap, JavaScript arrays, objects, functions, `forEach()`, `filter()`, and DOM manipulation by building a simple shopping website.
